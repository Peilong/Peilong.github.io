    How the code works

    Each day’s quotation is written in a substitution cipher: every letter is swapped for another letter, and the same letter is always swapped the same way. Spaces and punctuation stay put. If Q stands for E once, it stands for E everywhere.

    How to crack it

    Start with what you know about English. Short words help: a one-letter word is almost always A or I, and three-letter words are often THE or AND. Letter counts help even more: E, T, A, O, I and N are the most common letters in English, so the most common letters in the puzzle are good first guesses. Counting letters to break a code is called frequency analysis, and the Arab scholar al-Kindi described it in the 9th century.
